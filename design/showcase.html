How a coding agent sees a folder

Mocks for a desktop app (Electron + Vite) that resolves everything shaping Claude Code's view of a file: the CLAUDE.md chain, memory, settings and permission rules at every level, hooks, skills, agents and MCP servers. The example project throughout is ~/projects/acme/shop-api with src/api/payments.ts selected. Frames are live HTML; scroll inside is disabled, open one full size to inspect.
